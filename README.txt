ГОТОВЫЙ САЙТ ДЛЯ GITHUB PAGES

1. Открой index.html.
2. В самом низу найди блок CONFIG.
3. Замени:
   PASTE_AFFILIATE_LINK_HERE
   PASTE_ERID_HERE
   PASTE_ADVERTISER_HERE

4. Не меняй имена файлов в папке assets.
5. Загрузи папку сайта в GitHub-репозиторий.
6. GitHub: Settings -> Pages -> Deploy from a branch -> main -> /(root).

Важно:
- На сайте нет собственной кредитной анкеты.
- Нет автоперехода.
- Нет ретаргетинга.
- Нет Метрики/рекламных пикселей.
- Используются предоставленные рекламные креативы.
- ERID и рекламодателя нужно взять из инструкции партнёрской сети, не придумывать.
